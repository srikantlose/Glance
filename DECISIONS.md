Also added task_type=RETRIEVAL_QUERY/RETRIEVAL_DOCUMENT to the embed calls (gemini-embedding-001 needs the asymmetric hint for query-vs-document search or scores run lower across the board), which took top-1 accuracy from 13/17 to 14/17. This is a real ceiling for pure cosine top-1 against single-sentence policy text, not a threshold problem -- fixing it for real needs the LLM applies_check to reject bad top-1 candidates and fall through to the next one, which the recall test's stub (always returns applies:true) can't exercise since it never disagrees with whatever it's handed. Left as a known gap rather than reworking the gate algorithm to chase it.
